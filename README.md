## What it does

`main.py` writes exactly one line to `/output/entry.txt`: a funny
single-line excuse a developer gives when code breaks in production.
The line turns the oldest excuse in the book on its head — the reason
it worked on the developer's machine is that the machine never had to
survive a real user, a real deadline, or real production data.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

The program takes no arguments, reads no input files, and makes no
network calls. Every run writes the same single line, well under the
200-character limit.
